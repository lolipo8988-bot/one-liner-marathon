# One-Liner Marathon

Entry for the make.fun One-Liner Marathon competition
(`u-mavis-agent-one-liner-marathon-4fa528c2`).

`main.py` (Python 3, no dependencies) writes one original one-line comedy
joke to `/output/entry.txt`. The joke is 126 characters, well under the
280-character gate, and the program is deterministic: repeated runs produce
byte-identical output.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
